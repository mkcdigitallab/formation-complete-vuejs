# Formation complète Vue.js — du débutant au développeur autonome

> Objectif : maîtriser Vue 3, son écosystème et la méthode de travail d'un développeur frontend professionnel. Cette formation privilégie la compréhension, la pratique et l'autonomie plutôt que la copie de solutions.

## Pour commencer

1. Lis [le plan complet](PLAN-DE-FORMATION.md).
2. Consulte [la méthode de travail](GUIDE-APPRENANT.md).
3. Suis les modules dans l'ordre et coche [ton suivi](SUIVI-DE-PROGRESSION.md).
4. Fais chaque laboratoire sans regarder la correction avant d'avoir essayé.
5. Termine chaque projet et chaque évaluation avant de déclarer une notion acquise.

## Règles de la formation

- Tu écris toi-même le code des laboratoires.
- Avant de coder, explique le besoin, les données, les événements et le résultat attendu.
- Une fonctionnalité terminée doit être testée manuellement et, quand c'est pertinent, automatisée.
- Ne confonds pas « ça marche » avec « je comprends pourquoi ça marche ».
- Garde les commits petits et explicites ; ne travaille pas directement sur `main` pour les projets.
- N'ajoute pas une bibliothèque sans pouvoir expliquer le problème qu'elle résout.

## Démarrage rapide

Prérequis recommandés : Node.js LTS, npm, Git et VS Code.

Créer un projet Vue avec l'outil officiel :

```bash
npm create vue@latest
cd nom-du-projet
npm install
npm run dev
```

Choisis les options selon le module étudié. Pour le tout premier exercice, évite d'activer des outils que tu n'as pas encore étudiés.

## Évaluation finale

Tu es prêt lorsque tu peux concevoir une application de gestion de bout en bout, expliquer son architecture, connecter une API, tester les parcours essentiels, corriger une anomalie et présenter tes décisions sans suivre un tutoriel.

**Le délai de 30 jours est un objectif intensif, pas une garantie de maîtrise.** La validation dépend de tes réalisations et de ta capacité à les expliquer.
