## Conseils
- La documentation officielle est la référence lorsque les tutoriels se contredisent.
- Ne mélange pas Vue 2 et Vue 3 : cette formation cible Vue 3 et la Composition API.
- Préfère les exemples utilisant `<script setup>` quand tu étudies la Composition API.
- Les versions des dépendances évoluent : suis les instructions officielles au moment de créer ton projet.
