# Évaluations

## Évaluation A — JavaScript (sans Vue)
Étant donné un tableau d'objets produits, savoir filtrer par nom, trier par prix, calculer un total et mettre à jour une quantité sans muter les données de manière accidentelle.

## Évaluation B — Réactivité
Expliquer `ref`, `reactive`, `computed`, `watch` et `.value`. Pour chaque notion, donner un exemple où elle est utile et une erreur fréquente.

## Évaluation C — Composants
Dessiner l'arbre parent/enfant, indiquer les props, les événements émis et le composant propriétaire de l'état. Corriger une tentative de mutation directe d'une prop.

## Évaluation D — API et navigation
Décrire les états d'une requête, gérer une réponse non-2xx, une réponse vide et une erreur réseau. Expliquer la différence entre paramètres de route et query string.

## Évaluation E — Qualité
Écrire des tests de calcul et de composant. Identifier un problème d'accessibilité, un risque de sécurité frontend et une optimisation prématurée.

## Examen final pratique (3 à 4 heures)
Construire une petite application de gestion de commandes avec :
- liste, recherche et filtre ;
- création/édition avec validation ;
- détail par route ;
- panier ou état partagé ;
- chargement API simulé ou réel ;
- erreurs et états vides ;
- au moins cinq tests pertinents ;
- README avec instructions.

### Barème /20
- Fonctionnalités et cas limites : 5
- Modèle de données et réactivité : 3
- Architecture et responsabilités : 3
- Gestion API et erreurs : 2
- Tests : 2
- Accessibilité et interface : 2
- Git, README et explication orale : 3

**Seuil conseillé : 15/20**, et capacité à expliquer le code sans lire une solution.
